# Citing IsaacSwim

If IsaacSwim helps your research, please cite it:

```bibtex
@software{chen_isaacswim_2026,
  author  = {Chen, Danyi},
  title   = {{IsaacSwim}: Underwater Robotics for {NVIDIA} {Isaac} {Sim}},
  year    = {2026},
  version = {0.1.1},
  doi     = {10.5281/zenodo.24375186},
  url     = {https://github.com/danyichen/IsaacSwim}
}
```

GitHub's **Cite this repository** button reads the same details from `CITATION.cff`. Please also
cite the projects your work relies on, such as
[Isaac Lab](https://github.com/isaac-sim/IsaacLab),
[MuJoCo](https://github.com/google-deepmind/mujoco) for the fluid model and
[OceanSim](https://github.com/umfieldrobotics/OceanSim) for underwater rendering and sonar.
